# db-visualizer

[English](README.md) | [日本語](README.ja.md)

**db-visualizer** は、PostgreSQL データベースを可視化するための無料のオープンソース・
セルフホスト型ツールです。接続文字列を指定するだけで、スキーマをドラッグ&ズーム可能な
**ER図**（実体関連図）として表示し、**外部キー（FK）関係**をたどって行単位でデータを
閲覧できます。書き込みは一切行われません。

## 主な機能

1. **DB全体のER図** — 全テーブル・カラム・外部キー関係をドラッグ可能なグラフとして表示。
   折りたたみ表示/キーのみ表示/全カラム表示を切り替え可能。テーブルをクリックすると
   その行を閲覧できます。
2. **リンクデータ図** — 1行を選択すると、その行と外部キーで直接つながる全テーブルの行を
   グラフ表示します（1ホップ、双方向）。各テーブルはページネーション対応で、
   カスタムクエリによる絞り込みも可能です。
3. **レイアウトの保存** — ドラッグしたノードの位置は `localStorage` に保存され、
   再読み込み後も維持されます。
4. **構造的に読み取り専用** — カスタムクエリを含む全てのクエリは Postgres の
   `READ ONLY` トランザクション内で実行されます。詳細はセキュリティモデルの項を
   参照してください。

## 必要環境

- 可視化したい Postgres データベース（対応は Postgres のみ。`information_schema` を
  使ってスキーマ情報を取得します）
- Docker、または Docker を使わない場合は Node.js 20 以上

## 実行方法

```bash
cp .env.example .env   # DATABASE_URL を編集
docker-compose up --build
```

http://localhost:4000 を開いてください。

同じマシンの Docker 上で Postgres を動かしている場合は、`DATABASE_URL` の
`localhost` の代わりに `host.docker.internal` を使用してください。

## セキュリティモデル

このツールは「運用ルール」ではなく「構造」によって読み取り専用です:

- カスタムクエリを含む全てのクエリは `READ ONLY` トランザクション内で実行されるため、
  このツールがデータベースを書き換えることはありません。
- クライアントから渡されるテーブル名・カラム名は、SQLに埋め込む前にホワイトリスト
  形式で検証されます。
- カスタムクエリ機能は、単一の `SELECT` 文のみを許可します。

さらなる安全対策として、可能であれば読み取り専用の Postgres ロールで接続することを
推奨します。
